# Portfólio | Daniel Filho

Site pessoal para apresentar meu perfil, minha formação, as tecnologias que estou estudando e alguns projetos que já fiz.

🔗 **Acesse o site:** https://daniel-filho-hub.github.io/Portifolio/

---

## Sobre o projeto

Criei este portfólio para praticar front-end e organizar, em um só lugar, o que aprendi no curso de Engenharia de Software. A ideia foi fazer um site limpo, que funcione bem no celular e no computador, sem exageros.

## Funcionalidades

- Layout responsivo, adaptado para celular, tablet e desktop
- Tema claro e escuro, com a escolha salva no navegador
- Menu que acompanha a seção que está na tela
- Navbar que ganha fundo translúcido ao rolar a página
- Seção de projetos com imagens e links para o GitHub
- Botão para baixar o currículo em PDF

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons e Devicons
- Google Fonts (Inter)

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Daniel-Filho-Hub/Portifolio.git
   ```
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador. Não é necessário instalar nada, porque o Bootstrap já está dentro do projeto.
